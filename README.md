### 그날의 추억을 기록하는 우리만의 네컷사진
```
👥 그룹 만들기 : 원하는 친구들과 그룹방을 만들어요

🗳️ 투표하기 : 함께 찍은 사진들을 다함께 투표해서 골라요

🏞️ 네컷 만들기 : 베스트 사진으로 네컷 사진이 만들어져요
```
